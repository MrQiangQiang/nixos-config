## 二、角色详细定义（用途 + 场景 + 诗意描述）

### 中性色（背景与前景）

| 角色 | 层级 | 用途定义 | 典型场景 | 模糊场景推理 |
|------|------|----------|----------|--------------|
| **Base** | 一级背景 | 主背景 | 应用框架、侧边栏、标签页、焦点上下文的扩展面板 | 任何需要最底层背景色的场景（窗口、页面、画布） |
| **Surface** | 二级背景 | 底座上的次要背景 | 卡片、输入框、状态栏、与焦点内容无关的面板 | 需要与 Base 区分但不突出的背景（面板、列表、工具栏） |
| **Overlay** | 三级背景 | 表面之上的三级背景 | 弹出窗口、通知、对话框、临时性面板 | 任何浮层、模态框、下拉菜单、提示框的背景 |
| **Muted** | 低对比度前景 | 低对比度前景 | 注释、忽略文件、禁用元素、未聚焦的文本 | 需要弱化显示的内容（占位符、过期信息、次要说明） |
| **Subtle** | 中对比度前景 | 中对比度前景 | 标点符号、运算符、标签名称 | 需要可见但不抢眼的元素（分隔符、元数据、状态文字） |
| **Text** | 高对比度前景 | 高对比度前景 | 普通文本、变量、活动内容、光标文本 | 任何需要阅读的主体内容（正文、标题、选中结果） |

### 强调色（语义与终端）

| 角色 | 诗意描述 | 用途定义 | 典型场景 | 模糊场景推理 |
|------|----------|----------|----------|--------------|
| **Love** | Per favore ama tutti（请爱所有人） | 诊断错误 / 终端红色 | 错误提示、删除的 Git 文件、内置命令/函数、亮红色终端色 | 任何表示危险、禁止、失败、删除、负向操作的场景 |
| **Gold** | Lemon tea on a summer morning（夏日早晨的柠檬茶） | 诊断警告 / 终端黄色 | 警告提示、字符串、亮黄色终端色 | 任何表示注意、提醒、需要关注但不紧急的场景 |
| **Rose** | A beautiful yet cautious blossom（美丽而谨慎的花朵） | 匹配搜索背景 / 终端青色 | 修改的 Git 文件、布尔值、函数、亮青色终端色 | 表示变化、差异、匹配、选中状态、温和强调的场景 |
| **Pine** | Fresh winter greenery（清新的冬日绿意） | 重命名的 Git 文件 / 终端绿色 | 条件语句、关键字、亮绿色终端色 | 表示成功、进行、确认、逻辑控制、正向流程的场景 |
| **Foam** | Saltwater tidepools（盐水潮池） | 诊断信息 / 终端蓝色 | Git 新增文件、对象键、标签、类型、亮蓝色终端色 | 表示信息、新增、数据标识、结构化内容的场景 |
| **Iris** | Smells of groundedness（沉稳的气息） | 诊断提示 / 终端洋红色 | 内联链接、合并和暂存的 Git 修改、方法、参数、亮洋红色终端色 | 表示提示、链接、合并、参数、可交互元素的场景 |

### 高亮色（交互状态）

| 角色 | 用途定义 | 典型场景 | 模糊场景推理 |
|------|----------|----------|--------------|
| **Highlight Low** | 低对比度高亮 | 光标行背景 | 需要轻微区分当前行/项但不刺眼的场景（悬停、当前项） |
| **Highlight Med** | 中对比度高亮 | 选区背景（搭配 Text 前景） | 需要明确表示选中区域的场景（文本选择、多选高亮） |
| **Highlight High** | 高对比度高亮 | 边框、光标背景（搭配 Text 前景） | 需要强边界感的场景（焦点框、分割线、光标、表格边框） |
