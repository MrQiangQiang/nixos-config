# 04 磁盘布局

> 方案：**disko 声明式 + btrfs 子卷**，单盘 Samsung 990 Pro 2TB。未来 HDD 加入做冷热分层。

## 设计理由

- **声明式**：分区方案与系统配置一起 Git 管理
- **一键部署**：换盘/重装直接复现相同布局
- **子卷共享空间**：无需预分配各分区大小
- **zstd 透明压缩**：代码和文本节省 20-40%
- **无需 Timeshift**：NixOS generation 本身是原子快照

## 分区

| 设备 | 大小 | FS | 挂载点 |
|------|------|-----|--------|
| nvme0n1p1 | 512MB | FAT32 | /boot/efi |
| nvme0n1p2 | 2GB | ext4 | /boot |
| nvme0n1p3 | 剩余 | btrfs | / (全部子卷) |

## 子卷

| 子卷 | 挂载点 | 职责 |
|------|--------|------|
| @ | / | 系统根 |
| @home | /home | 用户数据 |
| @nix | /nix | Nix store（隔离，快照时排除） |
| @var_cache | /var/cache | 包缓存 |
| @var_log | /var/log | 日志 |
| @ollama | /home/fugui/.ollama | Ollama 模型（独立子卷，快照排除） |
| @data_cold | /data/cold | 未来 HDD 冷数据预留 |

## zramSwap

压缩 RAM swap，无 NVMe 磨损，配合 systemd-oomd 快速 fail-fast，无需磁盘子卷。

```nix
zramSwap.enable = true;  # 在 hosts/desktop-1/default.nix 中，mkHost.nix 自动应用
```

## btrfs 维护

```nix
services.btrfs.autoScrub = {
  enable = true;
  fileSystems = [ "/" ];
  interval = "monthly";
};
```

## 安装流程

```bash
# 1. NixOS ISO 启动 → 联网
# 2. 克隆配置仓库
git clone https://github.com/fugui/nixos-config /tmp/nixos-config

# 3. disko 一键分区（disko 已 pin 在 flake.lock 中）
nix run /tmp/nixos-config#disko -- --mode disko \
  /tmp/nixos-config/hosts/desktop-1/disk-config.nix

# 4. 生成硬件配置（不含文件系统 — disko 已处理）
nixos-generate-config --no-filesystems --root /mnt

# 5. 安装（合入 flake，一步构建全系统）
cp /mnt/etc/nixos/hardware-configuration.nix \
  /tmp/nixos-config/hosts/desktop-1/
nixos-install --flake /tmp/nixos-config#desktop-1 --no-root-password
reboot
```

## 未来 HDD 冷热分层

加入 4TB+ HDD 时，用符号链接实现冷热分层。bcachefs 已从内核移除，bcache 配置复杂收益低，符号链接最可控。

```
NVMe (热)          HDD (冷)
/data/cold/  ←──→ /data/hdd/archive
                    /data/hdd/backups
                    /data/hdd/models-large
```

### NixOS 配置（加 HDD 时）

```nix
fileSystems."/data/hdd" = {
  device = "/dev/sda1";
  fsType = "btrfs";
  options = [ "compress=zstd" "noatime" ];
};

# home-manager 符号链接
home.file."archive".source = config.lib.file.mkOutOfStoreSymlink "/data/hdd/archive";
```

### 操作步骤

```bash
sudo mkfs.btrfs -L hdd-cold /dev/sda1
# 更新 configuration.nix → sudo nixos-rebuild switch
sudo mkdir -p /data/hdd/{archive,backups,models-large}
sudo chown fugui:users /data/hdd/{archive,backups,models-large}
```

> 当前 `@data_cold` 子卷已预留，没有 HDD 时可先放冷数据，加 HDD 后用 `btrfs send/receive` 迁移。
