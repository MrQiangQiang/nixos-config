# 07 系统部署

> 架构：**flake-parts + mkHost.nix 多机方案。** 配置入口 `hosts/desktop-1/default.nix` → 共享模块 `modules/` + `home/`。
> disko 已 pin 入 flake.lock（`nix run .#disko` 即用 pin 定版本）。
> 手机热点 + VPN 为唯一推荐网络方案。离线备选仅有 `bootstrap-config.nix` 最小自举配置。

## 网络方案：ISO 环境如何访问 GitHub

NixOS 裸机安装时，disko / nixos-install 要从 GitHub 拉源码。中国网络环境下这需要代理。

### 最简方案：手机热点 + VPN

手机开 VPN → 开热点 → 笔记本连手机热点。所有流量经 VPN 出去，ISO 环境零配置。

```bash
# ISO 启动后
# 1. 连 WiFi
nmtui
# → Activate a connection → 选手热点 → 输密码

# 2. 验证（直接走手机 VPN）
curl -I https://github.com
# HTTP/2 200 → 搞定，可以继续 disko
```

### 备用方案：bootstrap-config.nix（纯离线，无 GitHub）

如果手机方案不可用，用仓库根目录的 `bootstrap-config.nix`。这是一个 52 行最小自包含配置：

```
bootstrap-config.nix 提供：
  systemd-boot + EFI + NetworkManager + SSH（密钥登录）+
  Nix 二进制缓存镜像（清华/中科大/上交）+
  fugui 用户（带 laptop-1 SSH 公钥）+
  时区/UTF-8/固件
```

ISO 下操作：

```bash
# 1. 连 WiFi（nmtui）
# 2. 手动分区（gdisk /dev/nvme0n1 → ESP 512M EF00 + root 剩余 8300）
#    mkfs.fat -F32 /dev/nvme0n1p1
#    mkfs.btrfs -f /dev/nvme0n1p2
# 3. 挂载
mount -t btrfs -o compress=zstd /dev/nvme0n1p2 /mnt
btrfs subvolume create /mnt/@
#   ... 创建所有子卷，挂载到正确位置
mkdir -p /mnt/boot
mount /dev/nvme0n1p1 /mnt/boot
# 4. 放入 bootstrap-config
nixos-generate-config --root /mnt
cp bootstrap-config.nix /mnt/etc/nixos/configuration.nix
# 5. 安装
nixos-install --no-root-password
reboot
# 6. 首次启动后：
#    laptop-1: ssh fugui@desktop-1（用密钥登录）
#    git clone https://github.com/fugui/nixos-config ~/nixos-config
#    sudo nixos-rebuild switch --flake ~/nixos-config#desktop-1
```

> 主路径推荐手机热点，一步到位。bootstrap 备选路径需要手动分区 + 事后补 flake 部署。

## 安装前准备（Windows 环境）

### 单 U 盘方案

| U盘 | 用途 |
|-----|------|
| Kingston 62GB | Ventoy + NixOS ISO（已就位，hash 已验证） |

**无需第二根 U 盘。** 配置仓库从 GitHub 克隆，不在 U 盘上离线存放。手机热点 + VPN 提供网络。

### WSL2 数据备份

| 优先级 | 内容 | 大小 | 操作 |
|--------|------|------|------|
| 🔴 | `~/.ssh/` `~/.gnupg/` | <10MB | 凭据，必须搬 |
| 🔴 | `~/AI_System/win-to-nixos/` | <1MB | 迁移文档本身 |
| 🟡 | `~/.ollama/` | 27GB | 见下方决策 |

```bash
# WSL2 中
mkdir -p /mnt/c/Users/fugui/backup/
cp -r ~/.ssh ~/.gnupg /mnt/c/Users/fugui/backup/
cp -r ~/AI_System/win-to-nixos /mnt/d/   # 直接放 D: (Kingston)
```

Windows 侧：`C:\Users\fugui\.ssh\` `.gitconfig` `.aws\` `.azure\` → 复制到 D:

> `AI_System` 下其他目录都是 Windows 代码（Python/JS/C# 项目），Linux 下无效，不搬。

### Ollama 模型：导出还是重下载？

| 方式 | 耗时 | 前提 |
|------|------|------|
| 导出到 Kingston | 写 15min + 读 5min = ~20min | USB 3.0 100MB/s 读 / 30MB/s 写 |
| 重新下载 | 取决于网络 | 代理稳定 + GitHub 可达 |

**建议导出。** 27GB 模型压缩意义不大（本身已高度压缩）。直接 tar 打包：

```bash
# WSL2 中
cd ~
tar cf /mnt/d/ollama-models.tar .ollama/
# 约 15 分钟写入
```

安装后恢复：

```bash
cd ~
tar xf /run/media/fugui/KINGSTON/ollama-models.tar
```

## 裸机安装流程

> **架构说明：** 当前使用 flake-parts + mkHost.nix 多机架构。
> 配置入口 `hosts/desktop-1/default.nix` → mkHost.nix → 共享模块。
> disk-config.nix 已 pin 入 flake.lock（`nix run .#disko`），无需手动指定 GitHub URL。
>
> 完整结构见 `hosts/desktop-1/default.nix`（116 行），核心模块见 `modules/`。

### 阶段一：ISO 环境

```bash
# 0. 启动
#    Ventoy U 盘启动 → 选 nixos-minimal-26.11pre...iso
#    开机 GRUB 按 e → linux 行末加：pcie_aspm=off
#    （MT7925 WiFi 需要，否则 installer 里不认网卡）

# 1. 联网
nmtui                          # 连 WiFi / 手机热点

# 2. 设代理（两个方案二选一）
#    方案A: 手机热点+VPN → 已自动走代理，跳过
#    方案B: clash 二进制
cp /run/media/nixos/KINGSTON/clash-linux-amd64 /tmp/
/tmp/clash-linux-amd64 -f /tmp/config.yaml &
export HTTPS_PROXY=http://127.0.0.1:7890

# 3. 验证网络
curl -I https://github.com     # 必须 200

# 4. 克隆配置仓库
git clone https://github.com/fugui/nixos-config /tmp/nixos-config

# 5. disko 分区（pin 在 flake.lock 中）
#    此命令会清空 /dev/nvme0n1，创建 GPT + 3 分区 + 7 btrfs 子卷
nix run /tmp/nixos-config#disko -- --mode disko \
  /tmp/nixos-config/hosts/desktop-1/disk-config.nix

# 6. 生成硬件配置（不含文件系统 — disko 已处理）
nixos-generate-config --no-filesystems --root /mnt
cp /mnt/etc/nixos/hardware-configuration.nix \
  /tmp/nixos-config/hosts/desktop-1/hardware-configuration.nix

# 7. 安装（声明式，一步构建全系统）
nixos-install --flake /tmp/nixos-config#desktop-1 --no-root-password
reboot
```

### 阶段二：首次启动后

```bash
# 1. 登录（root 免密，或 SSH 密钥登录 fugui）

# 2. Tailscale 认证（国内环境先开 mihomo 代理）
sudo tailscale up

# 3. 克隆仓库到 ~/
git clone https://github.com/fugui/nixos-config ~/nixos-config

# 4. 正式部署（替换 ISO 环境临时安装的配置）
sudo nixos-rebuild switch --flake ~/nixos-config#desktop-1

# 5. chezmoi dotfiles（以 fugui 用户）
chezmoi init --apply https://github.com/fugui/dotfiles.git

# 6. 恢复 ollama 模型（如果导出过）
cd ~
tar xf /run/media/fugui/KINGSTON/ollama-models.tar

# 7. 收集硬件信息（发给 AI 补完配置）
lspci -D -d ::03xx                      # GPU bus IDs → 取消注释 PRIME offload
syncthing --device-id                   # → 填入 syncthing 模块
cat /etc/ssh/ssh_host_ed25519_key.pub   # → 填入 secrets/keys.nix
```

## 配置结构

实际配置文件由 flake-parts 多机架构管理，**不在本文件中**：

| 文件 | 路径 | 职责 |
|------|------|------|
| 主机配置 | `hosts/desktop-1/default.nix` | kernel, GPU, Ollama, swap, µcode, desktop, user |
| 磁盘布局 | `hosts/desktop-1/disk-config.nix` | disko 声明式分区 |
| 硬件配置 | `hosts/desktop-1/hardware-configuration.nix` | nixos-generate-config 生成 |
| Flake | `flake.nix` | flake-parts + 所有 inputs |
| 共享模块 | `modules/` `home/` | mkHost.nix 自动应用 |

> `nixos-install --flake ...#desktop-1` 一步构建全系统，不需要手动复制 nix 文件。

## 更新策略

```bash
cd ~/nixos-config
nix flake update                       # 更新 flake.lock
sudo nixos-rebuild build --flake .#desktop-1   # 构建验证
sudo nixos-rebuild switch --flake .#desktop-1  # 原子部署
```

> 远程部署：`nixos-rebuild switch --flake .#desktop-1 --target-host fugui@desktop-1 --sudo`

## 回滚

| 场景 | 操作 |
|------|------|
| 功能异常 | `sudo nixos-rebuild switch --rollback` |
| 启动失败 | systemd-boot 选旧 generation |
| GC | `sudo nix-collect-garbage -d && sudo nixos-rebuild boot` |

## 更新节奏

```
日常：nix flake update && sudo nixos-rebuild build
周常：nix flake update && sudo nixos-rebuild switch
每月：sudo nix-collect-garbage -d && sudo nixos-rebuild boot
```
