# 分诊标签

skill 以五个规范分诊角色来表达。此文件将这些角色映射到此仓库问题跟踪器中使用的实际标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue  |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 完全规格化，准备好给 AFK agent  |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现            |
| `wontfix`                  | `wontfix`            | 不会采取行动                     |

当 skill 提到一个角色时（例如"应用 AFK 就绪的分诊标签"），使用此表中对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
