# 术语表——构建优秀的 skill

skill 之所以优秀的领域模型。skill 的存在是为了从随机系统中获取确定性；根本美德是**可预测性**，下面的每个术语都是作用于它的杠杆。这是 [`writing-great-skills`](SKILL.md) 的披露参考。

术语按轴线分组：**调用**（skill 如何被到达）、**信息层次**（其内容如何排列）、**引导**（agent 的运行时行为如何被塑造），以及**修剪**（如何保持精简）。每个**失败模式**都位于治愈它的杠杆旁边，标记为_失败模式_。

任何定义中的**加粗术语**本身在此术语表中有定义；通过其标题查找它们。

## 可预测性

skill 使 agent 在每次运行中以相同_方式_行为的程度——相同的过程，而非相同的输出（头脑风暴 skill 应该_可预测地_发散；其 token 变化，其行为不变）。所有其他术语服务的根本美德——成本和可维护性是它的症状，而非对手。

_避免_：一致性、可靠性、鲁棒性、输出确定性

## 调用

skill 如何被到达——以及你为这个选择付出的两种负载。

### 模型调用

保留其**描述**字段的 skill，因此 agent 可以看到它并自主触发它——人类仍然可以输入它的名字，所以模型调用总是_包含_人类可达。没有仅模型的状态：描述只_增加_ agent 发现，从不移除人类的。在每个回合付出永久的**上下文负载**以换取这种可发现性。可被其他 skill 到达，因为使它可被 agent 发现的描述也使其可被调用。一个内容全是**参考**的模型调用 skill 也是共享参考的一个归宿：另一个 skill 可以调用它，所以多个 skill 需要的参考住在一个地方。仅当 agent 必须自行到达该 skill 时才选择模型调用；如果它除了手动从不触发，删掉描述，不付出上下文负载。

_避免_：能力、工具、能力

### 用户调用

剥离了**描述**的 skill——对 agent 不可见，只能由人类输入其名字到达（用户_独有_，而**模型调用**是用户_和 agent_）。用 agent 可发现性换取零**上下文负载**。因为它没有描述，除了人类没有东西可以到达它：没有其他 skill 可以触发它。

_避免_：过程、工作流、命令

### 描述

skill 的机器可读触发器，以及**模型调用** skill 被迫始终加载的唯一**上下文指针**。它的存在_即是_调用轴线：保留它，skill 就是模型调用的（且可被其他 skill 到达）；删除它，skill 就是**用户调用**的，只能由人类到达。模型调用 skill 的**上下文负载**的来源。

_避免_：frontmatter、摘要

### 上下文指针

保存在 agent 上下文中的引用，命名某个上下文外材料并编码到达它的条件。**描述**是顶层上下文指针（上下文窗口 → skill）；指向披露文件的指针是低一级的同一对象。它的措辞，而非目标，决定了 agent _何时_到达——以及_多可靠_。一个必须有的目标放在措辞薄弱的指针后面是一个方差 bug：首先修复措辞，仅在磨利失败时才内联材料。

_避免_：链接、引用、导入

### 上下文负载

**模型调用** skill 对 agent 上下文窗口施加的成本——其**描述**，始终加载，消耗 token 和注意力。**用户调用** skill 通过没有描述而逃避的，以及对拆分成更多模型调用 skill 的刹车。

_避免_：token 成本、上下文膨胀

### 认知负载

**用户调用** skill 对人类施加的成本——他们必须在脑中持有的东西：哪些 skill 存在以及何时使用每一个（人类是索引）。**模型调用**通过 agent 可发现性而移除的，以及对拆分成更多用户调用 skill 的刹车。不是一个要最小化的成本：它是人类能动性的代价，一些 skill 保持用户调用的原因。在人类判断重要的地方花费它；在不重要的地方移除它。

_避免_：人类索引、负担、开销

### 路由 skill

一个**用户调用**的 skill，其工作是指向你其他的用户调用 skill——命名每一个以及何时使用它——这样人类只需记住一个 skill 而非许多。它只能暗示，从不触发它们：用户调用 skill 没有**描述**，所以除了人类没有东西可以到达它们。当用户调用 skill 增多时的**认知负载**的治愈方法。

_避免_：调度器、菜单、注册表、索引、路由过程

### 粒度

你划分 skill 的精细程度。更细的划分消耗两种负载之一：更多**模型调用** skill 消耗**上下文负载**（更多描述挤在窗口中竞争注意力）；更多**用户调用** skill 消耗**认知负载**（人类要记住和使用的更多）。两种切割指导划分。按**调用**，在你有一个独特的**引导词**来触发它的地方拆分出一个模型调用 skill——一个你实际在提示中使用的触发词。按**序列**，在某个步骤的**完成后步骤**需要隐藏的地方拆分一连串**步骤**，因为将其隔离在自己的上下文中会清除后续内容。当心反向操作：合并序列会将每个步骤的完成后步骤暴露给后续内容，邀请过早完成。

_避免_：分块、模块化

## 信息层次

skill 的内容如何排列，以及每个部分在阶梯上位于多深。

### 信息层次

skill 内容按 agent 需要它的紧迫程度排序——一个阶梯，由两次切割产生：文件内还是在指针后面，以及步骤还是参考。阶梯层级：

- **步骤**——文件内，主要
- **参考**，文件内——次要
- **参考**，披露的——在**上下文指针**后面

没有**步骤**的 skill 只使用底部两层——通常是合理的扁平对等集（例如一次审查的每条规则在同一层级），这是一种好的安排，不是问题。层次独立于调用：一个 skill 可以是模型调用或用户调用，无论它全是步骤、全是参考，还是两者都有。当 skill 有步骤时，应该被披露的文件内参考会埋没它们，并将对它们的关注变成抛硬币——一个方差杠杆，不仅是可读性的。保持阶梯顶部可读；将你能推下去的都推下去。

_避免_：结构、组织、布局

### 步骤

agent 执行的有序操作——当 skill 有它们时，其内容的主要层级，也是它在 SKILL.md 中赢得位置的部分。并非每个 skill 都有步骤：一个 skill 可以全是步骤（`tdd`）、全是**参考**（一次审查），或两者都有，独立于调用。每个步骤以一个**完成标准**结束，清晰或模糊。

_避免_：工作流、指令、编排

### 参考

agent 按需查阅的材料——定义、事实、参数、示例、条件指令。当 skill 有**步骤**时，它是次要的；当 skill 没有时，它是全部内容；或者它完全生活在任何 skill 之外——参见**外部参考**。通过**上下文指针**到达，是**渐进式披露**的主要候选。

_避免_：辅助材料、文档、背景

### 外部参考

生活在 skill 系统之外的**参考**——一个普通文件，没有**描述**，没有**步骤**，不可调用——任何 skill 都可以指向它。不需要自行触发的共享参考的归宿，也是两个**用户调用** skill 可以使用的唯一共享归宿，因为两者都没有描述，所以都不能触发另一个。

_避免_：文档、资源、知识库

### 渐进式披露

将**参考**沿阶梯向下移动——从 SKILL.md 移出并放在**上下文指针**后面——使顶部保持可读。主要不是 token 优化；它是**信息层次**如何被保护的方式。由**分支**授权：披露只有某些分支需要的内容，内联每条路径都需要的内容，如果指针在必须有的材料上不可靠地触发，磨利其措辞，仅在失败时才拉回内联。

_避免_：惰性加载、分块

### 共置

将 agent 一次需要的材料放在一个地方——一个概念的定义、规则和注意事项在一个标题下，而非分散在文件中——这样阅读一部分就能将其邻近内容一起带来。**信息层次**的文件内伴侣：层次决定一个部分_位于多深_；共置决定_什么与它并列_。没有公式适用于**参考**正文的正确格式；测试是 skill 应该读起来像为 agent 编写的文档，分组的材料读起来像那样，而分散的则不会。不同于**重复**：那是在两个地方重复一个含义，而分散是将一个含义碎片化到许多地方。

_避免_：分组、聚类、内聚

### 蔓延

_失败模式。_ 一个单纯太长的 skill——SKILL.md 中太多行——独立于它们是否过时或重复。即使一个全活跃、全唯一的 skill 也会蔓延。它消耗可读性（agent 在行动前要涉水而过更多内容，注意力在多余部分变薄）、可维护性（每一行多出来的一行都是要保持**相关**的），以及 token。治愈方法是**信息层次**：将**参考**推到**上下文指针**后面，并按**分支**或序列拆分，使每条路径只携带它需要的内容。不同于**沉积**（来自过时积累的长度）和**重复**（来自重复含义的长度）——蔓延是长度本身，无论其原因为何。

_避免_：膨胀、长度、大小、冗长

## 引导

塑造 agent 运行时行为朝向**可预测性**的杠杆。

### 分支

skill 可以被调用的不同方式——skill 处理的一个案例——使不同的运行通过它走不同路径。一个有许多步骤的 skill 可能有许多分支；一个线性的没有。

_避免_：路径、案例、分叉

### 引导词

一个紧凑的概念——也称为 Leitwort——已经存在于模型的预训练中，agent 在运行 skill 时用它来思考。它通过调用模型已有的先验，以最少的可能 token 编码一个行为原则（例如_课程_、_最近发展区_、_战争迷雾_、_示踪子弹_）。作为 token 重复，而非作为句子，它在 skill 中积累一个分布式定义并锚定一整片行为区域。自造一个词如果你清晰定义它可以工作，但一个编造的词不招募先验——你在定义 token 上付出预训练词免费给予的东西。首先寻找一个已有的词。

引导词两次服务于**可预测性**。在正文中它锚定**执行**——agent 每当概念出现时都采取相同的行为，在扁平参考中它将注意力集中在要寻找的一类东西上，每次运行招募正确的检查。在**描述**中它锚定**调用**——而且不仅在 skill 内：当同一个词出现在你的提示、你的文档和你的代码库中时，agent 将这种共享语言链接到 skill 并更可靠地触发它。用你想要 skill 时实际使用的引导词来措辞描述。

_避免_：关键词、术语、母题

### 完成标准

告诉 agent 一个工作单元已完成的条件——它判断的目标。两个属性使它成为杠杆，而非仅仅是品质。其**清晰度**（agent 能区分完成与未完成吗？）抵抗**过早完成**——一个模糊的边界（"理解达成"）让 agent 声明完成并滑到下一步；这个轴线需要_步骤_才能生效，因为过早完成是步骤之间的失败。其**要求**（它需要多少）设定**基础工作**——"每个修改的模型都被考虑"迫使彻底的工作，而"产生一个变更列表"则不会——而这个轴线_不_受步骤约束：它可以约束扁平参考体，这就是没有步骤的 skill 如何仍然携带一个穷尽性标准（"每条规则都已应用"）。最强的标准既可检查又穷尽。

_避免_：完成条件、退出条件、停止规则

### 基础工作

agent 在单个步骤内在幕后做的工作——读取文件、探索代码库、进行更改、挖掘它需要的东西而非卸载给用户。它位于步骤结构之下：从不作为自己的步骤编写，潜伏在措辞中，由 agent 而非 skill 控制。**完成后步骤**跨步骤拉力的步骤内对应物。由**引导词**（_全面_、_彻底_）或要求工作穷尽的**完成标准**提升——包括应用于扁平参考的要求轴线，这就是驱动扁平参考的 skill 覆盖其所有层级的东西。当该要求缺失或**过早完成**缩短步骤时变薄。

_避免_：范围、努力、勤勉、覆盖

### 完成后步骤

当前步骤之后的**步骤**。可见时，它们将 agent 拉向**过早完成**——看到的越多，拉力越强；防御是通过将步骤序列拆分为两个来隐藏它们。

_避免_：视野、战争迷雾、前瞻

### 过早完成

_失败模式。_ 在真正完成之前结束当前步骤，因为 agent 的注意力滑向已完成而非工作。步骤之间的失败：它需要**步骤**才能发生——一个没有步骤的 skill 提前退出不是过早完成，而是未满足要求下薄弱的**基础工作**。两种力量之间的拉锯：可见的**完成后步骤**（向前拉）和**完成标准**的清晰度（阻力——一个锐利、可检查的标准站得住；一个模糊的让步）。模糊性是必要条件：一个锐利的边界无论后续步骤有多少可见都抵抗拉力，所以一个从不急躁的步骤不需要防御。两个杠杆支撑一个确实急躁的步骤，但按顺序使用它们：**首先磨利边界**——它是局部的且廉价的。只有当标准不可减少地模糊_且_你确实观察到急躁时，才**隐藏后续步骤**——而且隐藏只在真正的上下文边界上有效（用户调用交接或子代理调度；内联模型调用将后续步骤留在上下文中且什么都不清除）。基础工作薄弱的一个原因，但与之不同：即使一个步骤运行到完全完成，基础工作也可能薄弱。

_避免_：过早关闭、急躁、急促、走捷径

### 否定

_失败模式。_ 通过禁止来引导——告诉 agent _不要_做什么——将被禁止的行为拖入上下文并使其_更_可及，而非更少。_不要想大象_，大象就是全部；_永远不要写冗长的注释_，冗长就是 agent 刚读到的模式。否定是一个被强激活概念覆盖的弱修饰符，所以禁令半读为做这件事的指令。其**引导词**是_大象_：禁命名入框架的任何东西。治愈：提示**正面**——描述目标行为（"写一行注释"），使被禁止的永不被说出。禁令仅作为你无法正面表达的行为的硬护栏赢得其位置；即便那时也将其与正面目标配对，使注意力落在该做什么上。

_避免_：讽刺反弹、否定提示、粉红大象

## 修剪

保持 skill 精简——每个补救措施与它治愈的失败配对。

### 单一真相源

每个含义恰好生活在一个权威位置的理想状态，因此对 skill 行为的更改是一处更改。**重复**是其违反。

_避免_：归宿、规范位置

### 重复

_失败模式。_ 同一含义被给予多于一个**单一真相源**。它消耗维护（改一处，你必须改其他处）、消耗 token，并夸大显要程度——重复一个含义在阶梯上将其权重超过其真实排名。**引导词**的意外反面，后者通过重复 token 故意提高注意力，从不重复含义。

_避免_：重复、冗余

### 相关性

一行是否仍然与 skill 做的事情有关——保留什么的镜头。一行要么通过从不与任务相关（纯粹的陈述，或一个应该被披露的**分支**）失去相关性，要么通过过时：随着它描述的行为或世界变化而漂移过时。较短的 skill 更容易保持相关，因为每一行检查起来更廉价。不同于**空操作**：相关性询问一行是否与任务有关，而非它是否改变行为。

_避免_：承重、过时、新鲜度

### 沉积

_失败模式。_ 在 skill 中沉淀且从未被清除的旧内容层，因为添加感觉安全而移除感觉有风险——所以过时和无关的行积累，你必须在它们中挖掘以找到仍然活跃的内容。任何没有修剪纪律的 skill 的默认命运；**相关性**的缓慢侵蚀，相对于**重复**的重复含义。

_避免_：堆积、膨胀、cruft、腐烂

### 空操作

_失败模式。_ 因为模型默认已经这样做而不改变任何事情的指令——你付出负载告诉 agent 它无论如何都会做的事。测试：一行是否改变行为相对于默认？一行可以完全**相关**且仍然是空操作。使**引导词**免费的相同先验使空操作毫无价值。

引导词是一种_技术_；空操作是对一行的_判定_——它们交叉。一个太弱而无法击败默认的引导词是空操作（当 agent 已经偏彻底时说_要彻底_），修复是一个通过判定的更强的词（_不留余地_），而非不同的技术。所以空操作测试——它是否改变行为相对于默认？——也是你评估引导词是否赢得其重复的方式。这是模型相对的，而非读者相对的：两个人对一行是否是空操作的分歧是对默认的分歧，通过运行 skill 而非辩论来解决。

_避免_：冗余指令、重述显而易见、赘述
